Please note that there will be a practice test on Class 8, which will take the
majority of the class time. This is the first of two practice tests.

\begin{itemize}[itemsep=4pt,topsep=0pt,leftmargin=15pt]
\item The practice test will be similar in format as the actual AP Physics C
  Mechanics exam, with both multiple-choice and a free-response sections.
  However,   the practice test will be substantially shorter.
  
\item The test covers all the topics discussed from Class 1 to 7, which
  include
  \begin{itemize}
  \item Kinematics (including solving simple differential equations)
  \item Single-body and multi-body dynamics
  \item Work-Energy principle
  \item Law of conservation of energy
  \item Impulse-momentum principle
  \item Collisions and conservation of momentum
  \item Centre of mass
  \item Circular motion
  \end{itemize}

\item The practice test will ``mimic'' hybrid testing method that is now used
  in all AP exams:
  \begin{itemize}
  \item Multiple-choice questions (MCQ) will be done digitally, on the web
    platform \texttt{classkick.com}. (The Bluebook app that AP exam uses is
    more sophisticated than ours.) Like the actual AP exams, once the MCQ
    section has completed, that portion of the test will be locked, and you
    will not be able to make more changes to it.
    
  \item Free-response questions (FRQ) will be visible to students after the
    MCQ section has ended (and after a brief break, and an short informational
    session about the FRQ). For the FRQ section, you
    will \emph{read} the questions on the platform, but you will \emph{write}
    your answers on a separate booklet. The booklet mimics the real AP exam
    booklet. Please download it and print it before class via this link:

    \begin{center}
      \Large
      \href{https://ossfiles.ca/index.php/s/triZ3GP7SXwQpSi}
           {https://ossfiles.ca/index.php/s/triZ3GP7SXwQpSi}
    \end{center}
    %For online classes,
    The booklet will also be sent to you via the Zoom chat window during class
    as well.

  \item Your teacher will give you instructions on how to scan and upload your
    work for the FRQs after the class ends.
  \end{itemize}
  
\item Unlike the actual AP exam, the first practice test will be
  \textbf{open-book}. You
  may use any resources from Meritus, including your own notes, slides,
  homework, and handouts. However, the longer you take to search through your
  notes, the less time you will have to answer the questions.

\item The PDF file for both sections of the test will only be made available to
  you after the test has been completed. Until then, you can only read the
  question via the web interface.
\end{itemize}
  
As this is the first time that we are using this hybrid testing method, your
teacher will give you more detailed instructions throughout the class. Good
luck!
